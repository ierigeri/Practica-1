# InSAR Geotechnical Time Series Analysis

This repository contains a Python-based workflow for analyzing and visualizing ground deformation time series derived from satellite InSAR data, with a geotechnical interpretation perspective.

##  Project Overview
The objective of this project is to explore deformation patterns and trends using time-series data and to relate them to geotechnical concepts such as slope stability and tailings facility monitoring.

##  Tools and Methods
- Python (Pandas, NumPy, Matplotlib)
- InSAR time series analysis
- Data cleaning and preprocessing
- Data visualization and trend interpretation
- Geotechnical interpretation concepts


##  Workflow
1. Import and preprocess deformation time series data  
2. Visualize displacement trends  
3. Analyze temporal patterns and potential anomalies  
4. Interpret results in a geotechnical context  

##  Academic Context
This project was developed as part of my academic training and professional internship in Geology.  
All data used in this repository is anonymized and for educational purposes only.
